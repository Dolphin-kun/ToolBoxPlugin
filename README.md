# ツールボックスプラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/ToolBoxPlugin/releases/latest)

## 概要
様々な機能をカスタマイズ可能なパネルからボタンで呼び出せるツールを追加するプラグインです。

## 使い方
1. 画面左上のメニューバーから、`ツール`内にある「ツールボックス」を選択してください。

## アイテム一覧（随時更新）
|カテゴリ|名称|機能|
|-|-|-|
|タイムライン|整列|選択した複数のアイテムを、指定した間隔で整列させます。|
|タイムライン|階段状に配置|選択した複数のアイテムを階段状（レイヤーと時間をずらして）配置します。|
|タイムライン|立ち絵配置|音声アイテムに合わせて、立ち絵アイテムを自動で配置します。|
|レイアウト|グループ化|選択した複数のアイテムをグループ化します。|
|テキスト|ルビ振り|テキストアイテムの漢字に自動でルビ（ひらがな/カタカナ）を振ります。|
|テキスト|テキスト分割|テキストアイテムを1文字ごと、または改行ごとに分割して配置します。|
|オーディオ|録音|マイクからの音声を録音し、タイムラインに配置します。|
|オーディオ|音声分離|動画等のアイテムから音声を分離します。|
|ユーティリティ|マクロ|登録した操作を上から順に実行します。よく使う手順を1ボタンにまとめられます。|
|ユーティリティ|ファイル・フォルダーを開く|指定したファイル・フォルダー・URLを開きます。|
|装飾|ラベル|パネルに見出しの文字を置きます。|
|装飾|区切り線|パネルに区切り線を引きます。|
|ショートカット|ショートカット|「元に戻す」「分割」など、YMM4の標準機能をボタンとして配置できます。|

## 主な機能
- **同じアイテムを何個でも配置**できます。設定画面の各アイテムで「この種類をもう 1 つ追加」を押してください。
- **配色の変更**：アイテムごとに背景色・枠の色・アイコンや文字の色・枠の太さ・角の丸みを設定できます。
- **ホットキー**：アイテムにキーの組み合わせを割り当てられます。文字入力と区別するため `Ctrl` / `Alt` / `Win` のいずれかを含む組み合わせのみ。
  YMM4のウィンドウに届いたキーだけを見るので、他のアプリには影響しません。
- **配置の元に戻す / やり直す**：パネル上で右クリック、または**マウスをパネルに乗せた状態で** `Ctrl+Z` / `Ctrl+Y`。タイムラインのUndoとは独立しています。
- **複数パネル**：右クリックから「パネルの追加」「パネルの複製」「パネル名の編集」ができます。

## アドオン
`<YMM4>\user\plugin\ToolBox\Addons\` に DLL を置くと読み込まれます。設定画面の「アドオン」から
削除・有効/無効の切り替え・フォルダーを開く操作ができます。

### アドオンを公開する
GitHub のリポジトリに **`ymm4-toolbox-addon`** トピックを付けると、設定画面の「アドオンを探す」に一覧表示され、
最新リリースに添付した `.zip`（中の DLL を取り込みます）または `.dll` からそのまま導入できるようになります。
`IToolBoxAddon.RepositoryUrl` にリポジトリの URL を書いておくと、導入済みかどうかを判定できます。
