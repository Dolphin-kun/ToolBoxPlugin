# ツールボックスプラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/ToolBoxPlugin/releases/latest)

## 概要
よく使う操作をボタンとしてパネルに並べ、クリック一発で呼び出せるようにする YMM4 用プラグインです。
ボタンの配置・大きさ・見た目は自由にカスタマイズでき、アドオンで機能を追加することもできます。

## 使い方
画面左上のメニューバーから、`ツール` 内にある「ツールボックス」を選択してください。

### 基本操作

|操作|やり方|
|-|-|
|アイテムを実行|クリック|
|アイテムを移動|`Ctrl` を押しながらドラッグ|
|アイテムの大きさを変更|`Ctrl` を押しながら右下のハンドルをドラッグ|
|アイテムごとの設定を開く|`Ctrl` + 右クリック → 「設定」（一部のアイテムは右クリックのみでも開きます）|
|アイテムを固定 / 非表示|`Ctrl` + 右クリック|
|アイテムをコピー|`Ctrl` + 右クリック → 「コピー」|
|アイテムを貼り付け|何もない場所で右クリック → 「アイテムを貼り付け」（別のパネルにも貼れます）|
|パネルのメニュー|何もない場所で右クリック|
|配置を元に戻す / やり直す|パネルにマウスを乗せた状態で `Ctrl+Z` / `Ctrl+Y`、または右クリックメニュー|

`Ctrl` を押している間はグリッドの枠線が表示され、移動・リサイズできる状態になります。
`Ctrl` を押している間はウィンドウのサイズ変更が無効になり、誤操作を防ぎます。

## アイテム一覧

|カテゴリ|名称|機能|
|-|-|-|
|タイムライン|整列|選択したアイテムを開始位置の早い順・遅い順にレイヤーへ並べ直します。|
|タイムライン|階段状に配置|レイヤー順に一定フレームずつずらして階段状に配置します。|
|タイムライン|立ち絵配置|音声のキャラクターに対応する立ち絵を、上下いずれかの隣接レイヤーへ配置します。|
|タイムライン|シーンへ移動|選択したアイテムを、新しいシーンや既存のシーンへまとめて移します。|
|タイムライン|隙間チェック|アイテムの間にできた 1F・2F といったわずかな隙間を探し、その位置へジャンプします。|
|タイムライン|ブックマーク|よく戻る位置を覚えておいて、前後のブックマークへ一気に移動します。|
|タイムライン|レイヤー一括編集|複数のレイヤーの名前・背景色・音量・有効/無効をまとめて変えます。|
|レイアウト|グループ化|選択範囲全体を覆うグループ制御を追加します。|
|テキスト|ルビ振り|テキスト・音声アイテムの漢字にルビ（ひらがな / カタカナ）を振ります。|
|テキスト|テキスト分割|1 文字ごと・改行ごとなどに分割し、縦または横に並べます。|
|テキスト|文字タグ|セリフやテキストに、色・サイズ・ルビ・ウェイトなどの文字タグをボタンで付けます。|
|オーディオ|録音|マイクから録音し、音声アイテムとして追加します。|
|オーディオ|音声分離|動画の音量を 0 にして、同じ音声を 1 つ下のレイヤーに音声アイテムとして追加します。|
|ユーティリティ|マクロ|登録した操作を上から順に実行します。|
|ユーティリティ|ファイル・フォルダーを開く|指定したファイル・フォルダー を開きます。|
|ユーティリティ|保存したアイテムを追加|選んでいるアイテムを覚えておいて、クリック 1 回でタイムラインに追加します。|
|装飾|ラベル|パネルに見出しの文字を置きます。|
|装飾|区切り線|パネルに区切り線を引きます。|
|ショートカット|ショートカット|「元に戻す」「分割」「再生」など YMM4 の標準機能 116 種類をボタンにできます。|

### マクロ
「音声分離 → 整列 → 階段状に配置」のように、繰り返す操作を 1 つのボタンにまとめられます。
手順は 4 種類から選べます。

- **ツールボックスの操作** : 他のアイテムが提供する操作（アドオンの操作も選べます）
- **YMM4 のショートカット** : 「元に戻す」「貼り付け」など本体の機能
- **パネル上のアイテム** : 開いているパネルに置かれているアイテムを、そのアイテム自身の設定で実行します。
  「ファイル・フォルダーを開く」のように設定が必要なアイテムはこちらから呼びます。別のパネルのアイテムも指定できます
- **待つ** : 次の手順まで指定ミリ秒待ちます。処理の完了を待ちたいときに挟みます

上から順に実行され、実行できない手順（選択が無いなど）は飛ばして続きます。

### ファイル・フォルダーを開く
素材フォルダーや外部ツールへの入口をパネルに置けます。

### シーンへ移動
クリックすると移動先を選ぶメニューが開きます。「新しいシーンへ」を選ぶと、
今のシーンと同じ画面サイズ・フレームレートのシーンを作ってそこへ移します。
右クリックの設定で、移動ではなく複製する / シーンの先頭に詰める / 移動先へ切り替える を選べます。

### 保存したアイテムを追加
ツールボックスの設定にある **「保存したアイテム」** で、タイムラインで選んだアイテムをいくつでも貯めておけます。
貯めたものはパネルに何も置いていなくても作れます。名前の変更・並べ替え・削除もここで行います。

パネルに「保存したアイテムを追加」を置くと、貯めたものの中から 1 つを紐づけられます。
以降はクリック 1 回で同じアイテムを追加できます。ボタンを増やせば、字幕・図形・装飾などを使い分けられます。

### 文字タグ
クリックすると編集ウィンドウが開きます。
上半分がセリフ・テキストの入力欄、下半分がタグのボタンです。

- **範囲に付ける** : 入力欄で文字を選ぶとボタンが押せるようになり、選んだ範囲をタグで囲みます
  （色 / サイズ / フォント / 位置 / 位置（文字比）/ 回転 / 字間 / ルビ）
- **その場に入れる** : カーソル位置にタグを入れます。範囲を選んでいるときはその直後に入ります
  （表示速度 / ウェイト / クリア）

読みや色など引数が必要なタグはポップアップが開き、組み上がるタグが文字列で確認できます。
書いた内容は **すぐアイテムに反映される**ので、YMM4 のプレビューでそのまま確かめられます。
`Ctrl+Z` または「1つ戻す」で 1 手ずつ、「最初に戻す」で開いた時点まで戻せます。
キャンセルで閉じれば、書いた内容はすべて元に戻ります。

タグの途中を選んでしまった場合はタグの外側まで自動で広げるので、タグが壊れることはありません。

### レイヤー一括編集
クリックすると設定ウィンドウが開きます。対象は **選択中のレイヤー** か **範囲指定** から選べます。

**有効 / レイヤー名 / 背景色 / 音量** のうち、チェックを入れた項目だけが書き換わります。
レイヤー名には `{0}`（レイヤー番号）と `{1}`（上から数えた連番）が使えます。
「リセット」を押すと、対象のレイヤーを YMM4 の既定値に戻します。

### 隙間チェック
中央の虫眼鏡ボタンで、指定フレーム数以下の隙間を一覧表示します。左右のボタンで前後の隙間へジャンプします。
探し方は **レイヤーごと** / **レイヤーをまたいで** / **すべて** から選べます。
「レイヤーをまたいで」は、どのレイヤーにもアイテムが無い空白時間を探します。
「すべて」では、同じ位置の隙間が二重に出ないようまとめて表示します。

### ブックマーク
中央のボタンで今の位置をブックマークし、左右のボタンで前後のブックマークへ移動します。
右クリックの設定で一覧の確認・名前の変更・削除ができます。

## カスタマイズ

### 同じアイテムを何個でも置く
設定画面の各アイテムにある「アイテム」欄で **＋** を押すと、同じ種類のアイテムを追加できます。
設定違いのアイテムを並べる（例：オフセットの違う「階段状に配置」を 2 つ）といった使い方ができます。
一覧の行を選ぶと、その個体に対して以降の設定が反映されます。

### 表示
アイテムごとに **アイコン / テキスト / 画像** から表示方法を選べます。
テキスト表示のラベルと、ホバー時のツールチップは「ボタンのラベル」で変更できます。

画像は **GIF アニメーション**にも対応しています。
画像を選んだときは、**枠いっぱいに広げる**か**縦横比を保つ**かを選べます。

### 配色
アイテムごとに以下を設定できます。「配色をリセット」で既定に戻せます。

- 背景色 / 枠の色 / アイコン・文字の色
- 枠の太さ / 角の丸み

### ホットキー
アイテムにキーの組み合わせを割り当てられます。
文字入力と区別するため **`Ctrl` か `Alt` を含む組み合わせ**のみ設定できます。
YMM4 のウィンドウに届いたキーだけを見るので、他のアプリの操作には影響しません。
同じキーを別のアイテムにも割り当てると設定画面に警告が出ます（実行時は先に配置されている方だけが反応します）。

### グリッド
「グリッドの調整」を **指定** にすると、縦・横のマス数と **セルの大きさ・セルの余白** を自分で決められます。

**自動** にすると、**サイズ** と **配置** を個別に自動へ回せます。自動にした項目の設定欄は隠れます。

|サイズ|配置|動き|
|-|-|-|
|オフ|オフ|「指定」と同じ（縦・横・セルの大きさをすべて自分で決めます）|
|**オン**|オフ|横のマス数だけ自分で決め、**セルの大きさはウィンドウの横幅ぴったり**に広がります。縦のマス数は入る分だけ自動で決まります|
|オフ|**オン**|セルの大きさは指定のまま、縦横のマス数がウィンドウに入るだけ並びます|
|**オン**|**オン**|「セルの大きさ」を目安に列数を決めたうえで、**横幅ぴったり**になるよう大きさを微調整します|

セルの枠線を常時表示するか、ドラッグ中のハイライト色なども変更できます。

### 円形ランチャー
設定画面の **「ランチャー」** で有効にすると、割り当てたキー（またはマウスボタン）を押している間、
マウスカーソルの周りに円形のメニューが出ます。離すとその項目が実行されます。

並びを空にしておくと、今のパネルのアイテムがそのまま並びます。
並びを自分で組む場合は、**パネルのアイテム / ツールボックスの操作 / YMM4 のショートカット / グループ**を追加できます。
グループにすると、そのグループにカーソルを合わせたときに子の項目が展開されます。

「画像を大きく表示」を有効にすると、画像を設定したアイテムは扇形いっぱいに画像が広がります（ラベルは出ません）。

### パネル
パネルは何枚でも開けます。パネルごとにアイテムの配置とグリッド数を独立して持ちます。
右クリックメニューから「パネルの追加」「パネルの複製」「パネル名の編集」ができます。
アイテムはコピー / 貼り付けでパネル間を移動できます。
名前を付けるとウィンドウのタイトルが「ツールボックス / 名前」になります。

### 配置の元に戻す / やり直す
アイテムの移動・リサイズ・追加・削除・固定を 50 手まで遡れます。
タイムラインの元に戻すとは独立していて、互いに影響しません。

## アドオン

`<YMM4>\user\plugin\ToolBox\Addons\` に DLL を置くと自動で読み込まれます。
設定画面の「アドオン」から、フォルダーを開く・再読み込み・削除・有効 / 無効の切り替えができます。
無効にしたアドオンはファイルを残したまま読み込みだけを止めます。

### アドオンを探す
設定画面の「アドオンを探す」で、GitHub のトピックに **`ymm4-toolbox-addon`** が付いたリポジトリを一覧表示します。
「導入」を押すと最新リリースに添付された `.zip`（中の DLL を取り込みます）または `.dll` をそのまま導入できます。
GitHub の API は認証なしだと問い合わせ回数に上限があるため、取得した一覧は 10 分間使い回します。
上限に達した場合は、いつ回復するかをメッセージで表示します。

### アドオンの作り方

`IToolBoxAddon` を実装したクラスを公開すると、ツールボックスがそれを読み込みます。

```csharp
public sealed class MyAddon : IToolBoxAddon
{
    public string Name => "My Addon";
    public string Description => "説明";
    public string Author => "作者名";
    public string Version => "1.0.0";
    public string? RepositoryUrl => "https://github.com/user/repo";

    public IReadOnlyList<DraggableItem> GetDraggableItems() => [new MyItem()];
    public IReadOnlyList<ToolItemSettings> GetSettings() => [new MySettings()];
}
```

アイテムは `DraggableItem`（見た目と操作の定義）と `ToolItemSettings`（保存される設定）の 2 つで構成します。

```csharp
public sealed class MyItem : DraggableItem
{
    public override Type SettingsType => typeof(MySettings);
    public override Type ViewType => typeof(MyItemView);
    public override Type? ViewModelType => null;
    public override Type? SettingsViewType => typeof(MySettingsPanel);  // 固有設定の画面 (不要なら null)
    public override Type? SettingsViewModelType => null;

    public override IReadOnlyList<ToolItemCommandDefinition> GetCommandDefinitions() =>
    [
        new("MyItemCommand",
            ctx => ctx.SelectedItems?.Any() == true,
            ctx => DoSomething(ctx.SelectedItems!, ctx.Timeline, ctx.UndoRedoManager),
            displayName: "何かする"),
    ];
}

public sealed class MySettings : ToolItemSettings
{
    public override ItemCategory Category => ItemCategory.Timeline;
    public override string DisplayName => "何かする";
    public override string Description => "設定画面に出る説明。";
    public override string IconPath => IconKeys.Star;
}
```

- コマンド名（`"MyItemCommand"`）は View 側の `ICommand` 依存関係プロパティ名と一致させてください。
- `displayName` を付けると、そのコマンドがマクロの手順一覧に表示されます。
- 実行に配置済みアイテムの設定インスタンスが必要な場合は `requiresItemParameter: true` を指定します（マクロの候補からは外れます）。
- `ctx`（`IToolBoxContext`）から `SelectedItems` / `Timeline` / `UndoRedoManager` / `FindItemSettings<T>()` にアクセスできます。
- **配色・ホットキー・複数配置・ツールチップ・設定画面の枠や背景は、アドオン側で何もしなくても自動で付きます。**
- 設定画面のまとまりを折りたたみたい場合は `Style="{DynamicResource ToolBoxSettingsSection}"` を付けた `Expander` が使えます。

#### パネルに置くビュー

ビューのルートを `UserControl` ではなく **`ToolBox.Controls.ToolItemView`** にすると、
**右クリックで `SettingsViewType` の設定画面が開く動きが自動で付きます**（もう一度右クリックで閉じます）。
`SettingsViewType` が `null` のアイテムでは何も起きず、右クリックはそのまま素通りします。

```xml
<tbView:ToolItemView x:Class="MyAddon.Views.MyItemView"
                     xmlns:tbView="clr-namespace:ToolBox.Controls;assembly=ToolBox"
                     ToolTip="{Binding DisplayName}">
    <Button Command="{Binding MyItemCommand, ElementName=Root}"/>
</tbView:ToolItemView>
```

設定画面を自分で組み立てたい場合は `CreateSettingsPanel()` を上書きしてください。

#### 設定画面の行

**`ToolBox.Controls.SettingsRow`** を使うと、見出しと入力欄が本体と同じ間隔で並びます。

```xml
<tbRow:SettingsRow Label="{x:Static toolbox:Texts.MyLabel}">
    <controls:ToggleSlider Value="{Binding IsEnabled, Mode=TwoWay}" HorizontalAlignment="Right"/>
</tbRow:SettingsRow>
```

見出しの列幅は `LabelWidth`、入力欄側の最小幅は `ContentMinWidth`、見出しの見た目は `LabelStyle` で変えられます。

公開するときは GitHub のリポジトリにトピック `ymm4-toolbox-addon` を付け、`RepositoryUrl` にその URL を書いてください。
「アドオンを探す」の一覧に載り、導入済みかどうかの判定にも使われます。
